## Turino application
This is an application created with next for booking tour.You can search tours by range of date,origin or destination or all of them, But for booking a tour you have to sign in
For sign in enter youe mobile number and then we send a code to your phone, enter the code and now you are now signed in.
Then you have to complete your information from your dashboard, use the drop down menu in header and choose "اطلاعات حساب کاربری" 
if you don't complete your information you have to complete them in registration page.
You can see your booked tours and your transactions in your dashboard.

## features
1. search based on range of date,origin,destination or all of them
2. booking tour
3. edit your information
4. see your profile,booked tours and transactions in dashboard

## Instalation
1. clone the repository
```bash
https://gitlab.chabokan.net/ma.lotfi29/turino
```
2. install dependencies
```bash
npm install
```
3. for backend use
```bash
https://github.com/milad-azami/travel-agency-api-torino
```
4. run application with ``` npm run dev ```
